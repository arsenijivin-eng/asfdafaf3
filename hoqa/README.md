# Hoqa bot

Обновление: после подписок пользователь проходит лёгкие вопросы. После правильного 5-го вопроса появляется отдельное задание на 10 комментариев (не NFT). Пользователь отправляет 10 скриншотов боту, после чего автоматически продолжается вопрос 6.

Админка поддерживает задания-подписки: `/addsub`, `/delsub`, `/subs`.
